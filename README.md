# VR Box · Quest — сервер

## Структура
```
server.js        — сервер (аккаунты, сохранение, онлайн, голос)
package.json
index.html       — игра (раздаётся сервером)
```

## Запуск на компьютере
```
npm install
npm start
```
Открой `http://IP-компьютера:3000` на телефоне (камера в браузере работает только по https или на localhost).

## Render
1. Залей папку на GitHub (3 файла: server.js, package.json, index.html).
2. Render → New → Web Service → выбери репозиторий.
3. Build Command: `npm install`  ·  Start Command: `npm start`
4. Открывай выданный адрес `https://....onrender.com` — игра и сервер на одном адресе, ничего вписывать не надо.

## Важно про сохранение
Аккаунты лежат в `data/accounts.json`. На бесплатном Render диск стирается при перезапуске —
аккаунты пропадут. Чтобы они жили вечно: подключи Render Disk (платно) и поставь переменную
`DATA_DIR=/путь/к/диску`, либо используй VPS/Railway с томом.
Настройки и установленные игры дополнительно хранятся в самом телефоне и при повторной регистрации
загружаются на сервер обратно.

## Переменные (необязательно)
`PORT`, `DATA_DIR`, `MAX_PER_ROOM` (по умолчанию 12).

## Если игра лежит отдельно от сервера
Открой её с параметром: `index.html?server=https://твой-сервер.onrender.com`
